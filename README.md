This repository contains a **Scientific Conference Organization Tool**, developed as part of a Design of Algorithms course.

The project demonstrates the application of Maximum Flow algorithms, namely Edmonds–Karp and Ford–Fulkerson, to solve scheduling and resource allocation problems within a conference setting.

- Rodrigo Fernandes Teixeira (up202404802@up.pt)
